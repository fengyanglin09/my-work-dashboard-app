# UI Frameworks And Frontend Libraries

Use this as a quick picker for common Angular UI libraries. The links are grouped by library so the main page, examples, docs, and source repo are easy to find.

## Suggested Angular Stack

For many internal Angular apps, this is a clean default stack:

```text
Angular Material + AG Grid Community + Font Awesome
```

That gives you standard app controls, a strong data grid, and a broad icon set without pulling in too many overlapping UI systems.

## AG Grid Community

AG Grid Community is useful when the page needs a serious data grid: sorting, filtering, pagination, column sizing, custom cell renderers, and large-table performance.

| Link type | Link |
|---|---|
| Main page | [AG Grid](https://www.ag-grid.com/) |
| Angular docs / quick start | [AG Grid Angular Data Grid Quick Start](https://www.ag-grid.com/angular-data-grid/getting-started/) |
| Install docs | [AG Grid Angular Data Grid Quick Start - NPM Install](https://www.ag-grid.com/angular-data-grid/getting-started/) |
| Demo / examples | [AG Grid Angular examples](https://www.ag-grid.com/angular-data-grid/getting-started/#example-angular-data-grid) |
| Community vs Enterprise | [AG Grid licence and pricing](https://www.ag-grid.com/license-pricing/) |
| Repo | [ag-grid/ag-grid](https://github.com/ag-grid/ag-grid) |

Quick install:

```bash
npm install ag-grid-angular
```

AG Grid Community is free and MIT licensed. Enterprise adds advanced grid features and requires a commercial license for production use.
