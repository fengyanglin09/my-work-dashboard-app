# Access GCP Prod Env

JIT access to GCP production:

1. Go to [ServiceNow](https://mcsm.service-now.com/) and create a new change record for RFC. It needs to be in implement stage.
2. Go to [SailPoint](https://electronicaccess.mayo.edu/identityiq/home.jsf) and complete JIT access with the RFC.
3. Go to [EPAM](https://epam.mayo.edu/) for the S account credential.
4. Go to [GCP Console](https://console.cloud.google.com) and authenticate with the S account.
